# Mastra - Planejador Financeiro Pessoal Inteligente

## Estrutura do Projeto

```
mastra/
├── agents/          # Agentes de IA (GastoGuru, BudgetWizard, etc.)
├── workflows/       # Fluxos de trabalho que orquestram os agentes
├── tools/          # Ferramentas que os agentes podem usar
└── index.ts        # Configuração central do Mastra
```

## Agentes Planejados

1. **GastoGuru 💸** - Analisa gastos
2. **BudgetWizard 🧙‍♂️** - Cria orçamento
3. **RiscoRex 🦖** - Avalia riscos financeiros
4. **SalárioSábio 📈** - Avalia renda e metas
5. **ConselheiroCósmico 🌌** - Consolida recomendações
6. **MaestroFinanceiro 🎼** - Orquestrador dos agentes
